# Contributing to FlowLang

Thank you for your interest in contributing to FlowLang! We welcome contributions from the community.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/andh-FlowLang.git`
3. Create a new branch: `git checkout -b feature/your-feature-name`
4. Make your changes
5. Commit your changes: `git commit -m "Add your feature"`
6. Push to your fork: `git push origin feature/your-feature-name`
7. Create a Pull Request

## Development Guidelines

### Code Style

- Follow the existing code style and conventions
- Write clear, descriptive commit messages
- Add tests for new features
- Update documentation as needed

### Testing

- Ensure all tests pass before submitting a PR
- Add tests for new functionality
- Include example programs demonstrating new features

### Documentation

- Update relevant documentation when adding features
- Add examples to the `examples/` directory
- Keep the specification up to date

## Reporting Issues

- Use the GitHub issue tracker
- Provide clear descriptions and examples
- Include steps to reproduce for bugs

## Code of Conduct

Please note that this project adheres to a Code of Conduct. By participating, you are expected to uphold this code.

## Questions?

Feel free to open an issue for questions or discussion.
