# FlowLang Documentation

Welcome to the FlowLang documentation!

## What is FlowLang?

FlowLang is a lightweight, structured natural-language dialect designed to bridge human reasoning and AI execution. It provides a way to express computational logic and workflows in a format that is both human-readable and machine-processable.

## Key Features

- **Natural Language Syntax**: Write in a format close to natural language
- **Structured Expressions**: Clear, unambiguous computational patterns
- **AI-Friendly**: Designed for seamless AI interpretation and execution
- **Lightweight**: Minimal syntax overhead
- **Human-Readable**: Easy to understand and review
